# C Programming Programs

A collection of standalone **C source files** and practice programs organized by topic and problem set.

## Overview

This repository contains `.c` programs focused on writing, compiling, and practicing C code without separate notes files.

### Topics Covered
- **Basics & I/O:** Starter programs, variables, data types, keywords, escape sequences, and standard input/output.
- **Control Flow & Functions:** Conditionals, loops, modular functions, and scope.
- **Memory & Aggregates:** Pointers, arrays, strings, and structures.
- **Practice Sets:** Solved walkthrough programs and homework exercises.
