# Pointers in C — Programs

Standalone `.c` practice programs demonstrating how pointers work in C, without separate notes files.

## Programs Included

- **Basics & Address-of / Dereference:** Declaring pointer variables, reading memory addresses with `&`, and dereferencing values with `*`.
- **Pointer Arithmetic:** Incrementing/decrementing pointers, pointer differences, and how step size scales with the pointed-to type.
- **Pointers & Arrays:** Array decay to pointers, element access via pointer arithmetic, and traversing arrays.
- **Pointer-to-Pointer:** Multi-level indirection (`**ptr`) and accessing values across pointer chains.
- **Pointers & Functions:** Call by reference using pointer arguments to modify values in the caller scope.
